### '소화기'는 어떤 서비스인가요?
'아 맞다, 까먹었다!' 🤯 하고 발등에 불 떨어져 본 분들을 위한 'AI 일정 진압' 서비스입니다.

"달력 예쁘게 꾸밀 시간은 없는데... 일단 '까먹지 않는 게' 제일 중요해!"라고 생각하는 분들, 바로 여러분을 위한 앱이죠.

저희의 핵심 가치는 '귀찮음이라는 불씨'를 원천 차단하는 것입니다. 복잡한 버튼 누를 필요 없이, 그냥 생각나는 대로 툭 던지세요. '소화기'가 알아서 척척 등록해 드립니다.

핵심 기능은 아래와 같습니다!
  - 자연어 일정 등록 : Vertex AI Gemini와 Spring AI를 활용해 한 문장에서 일정 정보를 추출합니다.
  - 일정/할 일 분류 : 시간 정보가 있는 일정은 'SCHEDULE', 없는 항목은 'TODO'로 분리해 조회합니다.
  - 푸시 알림 : 오전 9시 당일 일정 알림, 매주 수요일 재등록 유도 메세지를 FCM으로 발송합니다.
  - 온보딩 체크 : 일정 등록 여부를 추적해 온보딩 완료 상태를 알려줍니다.

### '소화기'의 다음 스텝은 무엇인가요?
저희 '소화기 정예 소방대'가 더 많은 분들의 '발등에 떨어진 불'을 꺼드리기 위해, '출동 구역'(서비스 대상)을 대폭 넓힐 계획입니다! (즉, 더 많은 유저분들을 환영한다는 뜻이죠!) 👨‍🚒👩‍🚒

그리고 곧 '소화기'가 더 강력하게 업그레이드됩니다!

지금까진 '불씨(일정) 하나'씩만 껐다면, 앞으로는 "월요일 3시 회의, 수요일 5시 미팅, 아 그리고 금요일 마감!"처럼 한 문장 속에 숨어있는 '연쇄 화재'도 한 방에 싹 진압해버리는 '멀티 일정 추출' 기능을 탑재할 예정입니다!
